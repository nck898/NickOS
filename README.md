# [NickOS](https://nick-os.vercel.app/) 🍎

A retro Y2K-inspired web operating system built with React and TypeScript. Inspired by both [RyoOS](https://os.ryo.lu/) and [PostHog.com](https://posthog.com/), this was built with Cursor, Codex, and my own codin skills :)

Test it out [here](https://nick-os.vercel.app/)

## Features

- 🖥️ **Desktop Interface** - Clickable desktop icons for launching apps
- 📊 **Top Menu Bar** - Classic menu bar with dropdown menus
- 🎯 **Dock Bar** - Bottom dock with hover magnification effects
- 🗑️ **Trash App** - Empty your trash with style
- 🎬 **Video Player** - Watch some classic Nick YouTube favorites
- 🐍 **Snake Game** - Retro snake with keyboard controls



## Tech Stack

- **React 19** - UI framework
- **TypeScript** - Type safety
- **Vite** - Build tool and dev server
- **CSS3** - Styling with retro Y2K aesthetics
